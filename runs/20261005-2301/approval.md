## 확인 전에 할 일 (사람)
- Vercel 프로젝트 환경변수 `GEMINI_API_KEY` 를 Preview·Production 에 넣고 이 브랜치 배포를 Redeploy. 키가 없으면 "AI 추출을 쓸 수 없어요(서버 설정)" 안내만 나옴

## 확인 요청 사항
1. 교사·admin: 재주문 알림(/reorder) → "실험 매뉴얼 올리기" → /manual
2. 실제 실험 매뉴얼 파일(PDF·JPG·PNG, 4MB 이하) + 조 수 → "AI 추출" → "사용량을 찾고 있어요" → 추출 결과 확인 표
3. 표: 시약명 · 1조 사용량(고칠 수 있음) · 단위 · 1반 1회 필요량(= 사용량 × 조 수). 행마다 "우리 학교 시약" 자동 연결(틀리면 바꾸기), 등록되지 않은 시약은 저장에서 빠짐
4. "확인 후 저장" → "재주문 기준을 저장했어요" → 재주문 알림으로. 재고가 새 기준보다 적은 시약이 알림 카드로 보이고 "1반 1회 실험량 N × M조 기준" 표시
5. 이미 기준이 있는 시약은 더 큰 값만 반영(작으면 그대로)
6. 학생은 /manual 에 들어갈 수 없고 진입 링크도 없음

## 자동 테스트로 확인하지 못한 것 — 미리보기에서 꼭 확인
- **실제 Gemini 추출**: 로컬에 키가 없어 자동 테스트는 가짜 추출 결과로 화면·저장을 검증했고, 실제 호출은 "키 없음" 안내까지만 확인. 모델(gemini-3.5-flash-lite)·요청 형식이 실제로 동작하는지, 추출 품질, 응답 시간은 미확인
- 호출 제한(분당 5회)의 실제 동작 — 서버리스 특성상 인스턴스별로만 셈

## 시안과 다른 점
- 표의 "우리 학교 시약" 선택 줄·삭제·기존 기준 안내는 시안에 없는 추가(사용자 결정)
- 단위는 글자가 아니라 선택 상자(병·mL·g)
- 조 수 기본값은 빈 값(시안은 6), 파일 선택 뒤 "다른 파일 선택·지우기" 줄 추가
- 시약 자동 연결은 이름이 같거나 꾸밈말·농도·수화물 표기만 다를 때만(다른 시약 오연결 방지) — 나머지는 직접 고름
