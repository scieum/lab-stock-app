## 확인 요청 사항
1. 시약장이 없는 학교: /cabinets (데스크탑 nav "시약장 설정", 홈의 "시약장 추가") → "아직 시약장이 없어요" → "+ 시약장 추가" → "1번 시약장"
2. 문 형태(양문형/단문형)·단 수(3단/4단)를 고르면 배치도가 바로 바뀜
3. 칸을 눌러 보관 분류를 여러 개 지정 → 섞으면 위험한 조합이면 주의사항 표시 → "저장"
4. 시약장 여러 개: 추가, 위쪽 pill 로 전환, 이름 바꾸기, 삭제(배치된 시약은 "칸 없음"으로, 시약은 지워지지 않음)
5. 학생 계정: 배치도·주의사항은 보이고 편집·추가·저장은 없음
6. 상단 학교명을 누르면 "로그아웃" 메뉴 → 로그인 화면으로

## 시안과 다른 점
- 데스크탑은 명세 문장(단일 열)이 아니라 프레임 11-desktop 의 2열 배치를 따름
- 저장하지 않은 편집은 시약장을 전환하거나 화면을 떠나면 확인 없이 버려짐(시안에 규정 없음)
- 로그아웃 메뉴는 시안에 없는 요소(사용자 결정), 학교명 옆에 작은 화살표 표시 추가

## 결정이 필요한 것
- 모바일에서 교사·admin 이 화면 11 로 갈 링크가 없음(시약장이 1개 이상일 때): 탭바에 없고 홈 빠른 실행은 학생만 "시약장 보기". 데스크탑은 nav 에 있음
- 로그아웃은 그 계정의 모든 기기에서 로그아웃됨(이 기기만으로 바꿀 수 있음)

## 아직 없는 것
- 시약을 칸에 넣는 기능(시안에 없음) — 새 시약은 모두 "칸 없음"
- 시약장 QR 인쇄(화면 12 QR 스캔의 전제) — 시안에 없음
