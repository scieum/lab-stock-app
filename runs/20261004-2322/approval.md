## 확인 요청 사항
1. admin 로그인 → 홈 "사용자 관리" 또는 nav "사용자 관리" → /users: "{학교명} 사용자 N명", 역할별 인원, 멤버 목록(본인 행 "나")
2. 초대: "초대" → 이메일 여러 개 + 역할(학생/교사) → "N명 초대" → "초대 대기 (N)" 에 표시. "초대 링크 복사" 로 회원가입 주소 복사 (메일은 보내지 않음)
3. 초대된 이메일로 우리 학교에 가입하면 초대한 역할이 붙음
4. 멤버 행 › → 역할 변경(학생/교사/admin) → "역할을 바꿨어요"
5. "사용자 삭제" → 확인 → 학교에서 내보냄(기록은 남고 이름은 "삭제된 사용자")
6. 마지막 admin 은 역할을 바꾸거나 삭제할 수 없음, 본인은 삭제할 수 없음
7. 학생·교사는 /users 에 들어갈 수 없고 진입 링크도 없음
8. 내보내진 사용자: 열려 있던 화면은 "소속 학교가 없어요" + 로그아웃, 새 로그인은 "가입이 끝나지 않은 계정" 안내 → 같은 이메일·비밀번호로 회원가입하면 다시 들어옴

## 시안과 다른 점
- 초대는 이메일만 입력(시안의 "이름" 입력 없음), 메일 발송 없음
- 시트 오른쪽 위에 × 닫기 버튼 추가(시안에는 닫기 수단이 없음)
- 삭제 확인에 "{이름} · 사용·입고 기록은 남아요" 한 줄 추가
- 초대 취소 기능 없음(시안에 없음)

## 자동 테스트로 확인하지 못한 것
- 내보낸 사용자의 재가입(회원가입 화면 경유) — 테스트 학교는 실제 NEIS 학교가 아니라 가입 API 를 통과할 수 없음. DB 수준 재등록은 검증됨
- 내보낸 사용자가 남긴 기록의 "삭제된 사용자" 표시 — 테스트 잔여물 문제로 생략
