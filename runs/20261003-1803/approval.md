## 확인 요청 사항
1. 교사·admin 로그인 → 홈 "입고" 또는 nav "입고·시약 등록" → /intake
2. 새 시약 등록: 시약명·종류(보관 분류 8종)·재고량+단위(병·mL·g)·입고일·MSDS 주소 → "시약을 등록했어요" → 시약 목록에 표시
3. 기존 시약 입고: 검색 → 선택 → 수량(스테퍼·1·5·10) → "현재 N → 입고 후 M" → 입고 → "입고를 기록했어요" → 재고 증가
4. 검색 0건이면 "찾는 시약이 없어요" + "새 시약 등록" 으로 전환
5. 학생 계정은 /intake 에 들어갈 수 없고(홈으로), 진입 링크도 없음
6. 같은 이름 시약은 다시 등록되지 않음("같은 이름의 시약이 이미 있어요")

## 시안과 다른 점 (프레임에 없던 부분)
