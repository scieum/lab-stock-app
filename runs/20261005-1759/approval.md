## 확인 요청 사항
1. 홈(교사·admin)의 빠른 실행에 "시약장 설정" 추가 — 휴대폰에서 시약장을 만든 뒤에도 다시 들어갈 수 있음
2. 재주문 알림(/reorder, 교사·admin): 홈의 재주문 카드 또는 nav "재주문 알림" → 재고가 기준보다 적은 시약 카드(필요량 / 현재 재고, 알림 날짜)
3. "판매처 연결" → 판매처 선택 → "확인" → 그 판매처 사이트가 새 창으로 열림
4. 판매처 설정(/vendors, admin): 재주문 알림의 "판매처 등록" 또는 nav "판매처 설정" → 우리 학교 판매처 등록·수정·삭제, 공통 목록(11번가·G마켓·오피스안·퍼스트과학)
5. 학생은 재주문 알림·판매처 설정에 들어갈 수 없고 진입 링크도 없음, 교사는 판매처 설정에 들어갈 수 없음

- 판매처 연결 "확인" 뒤 "사이트를 새 창으로 열었어요. 열리지 않았다면 [직접 열기]" 안내 줄(팝업 차단 대비, 시안에 없음)
